# Oparysh Chinila v2026.10.01

First Oparysh Chinila rescue ISO.

## New

- **Eblan Browser** vendored offline into `/opt/eblan-browser` (launcher: `eblan`).
- **Eblanity CLI** vendored offline as `/usr/local/bin/eblanity`.
- Arch packages for PyQt6 / WebEngine / ffmpeg so the browser runs without network after boot.
- Rescue menu and helpers rebranded to Oparysh Chinila (`oparysh-chinila`, `oparysh-chinila-mount`).
- Claude Code, Codex, and OpenCode removed from the live image.

## Fixed

- Build path vendors Eblan/Eblanity before applying the rescue layer.

## Download

Write the `.iso` to a USB stick, boot the Oparysh Chinila entry, then run `eblan`, `eblanity`, or `oparysh-chinila`.
